# 📍 Красная линия Екатеринбурга (Telegram Bot)

Интерактивный гид по главному пешеходному туристическому маршруту Екатеринбурга (включает все 39 локаций) в формате Telegram-бота. 
Разработано в рамках учебного/практического проекта.

## 🛠 Стек технологий
- **Язык**: Python 3.10+
- **Фреймворк**: aiogram 3.x
- **База данных**: SQLite (aiosqlite)
- **Хранение данных**: JSON (генерация базы данных через Python-скрипт)

## ✨ Основные фичи
1. **Мультиязычность**: Поддержка Русского, Английского и Китайского языков (выбор пользователя сохраняется в БД).
2. **Deep Linking (Глубокие ссылки)**: Бот умеет считывать параметры при запуске. Возможен запуск через сканирование QR-кодов на конкретных точках маршрута (например: `t.me/redline_ekb_bot?start=loc_5`).
3. **Обход лимитов Telegram API**: Интеллектуальное разделение сообщений. Если историческая справка превышает лимит подписи к фото (1024 символа), бот автоматически отправляет фотографию и текст отдельными сообщениями.
4. **Бесшовная навигация**: Инструкции к следующей точке, автогенерируемые ссылки на Яндекс.Карты по адресу локации и удобная inline-кнопка «✅ Я на месте».
5. **Динамические плейсхолдеры**: В случае отсутствия фотографий для определенной локации, бот на лету подставляет сгенерированные заглушки с названием места.

## 🚀 Инструкция по локальному запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/eva-cool-proger/redline-bot.git
   cd redline-bot
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # для Windows:
   venv\Scripts\activate
   # для Mac/Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корневой папке проекта и добавьте ваш токен бота (получить можно у [@BotFather](https://t.me/BotFather)):
   ```env
   BOT_TOKEN=ваш_токен_здесь
   ```

5. Запустите бота:
   ```bash
   python bot.py
   ```

## 📱 Как тестировать
После запуска бота сгенерируйте себе ссылку вида:  
`https://t.me/redline_ekb_bot?start=loc_1` *(доступны локации от loc_1 до loc_39)*.  
Перейдите по ней в Telegram, нажмите «Старт» и протестируйте маршрут.
