# 📍 Красная линия Екатеринбурга (Telegram Bot MVP)

Интерактивный гид по главному пешеходному туристическому маршруту Екатеринбурга в формате Telegram-бота. 
Разработано в рамках учебного проекта.

## 🛠 Стек технологий
- **Язык**: Python 3.10+
- **Фреймворк**: aiogram 3.x
- **База данных**: SQLite (aiosqlite)
- **Хранение данных**: JSON

## ✨ Основные фичи
1. **Deep Linking (Глубокие ссылки)**: Бот запускается через QR-коды на конкретных точках маршрута (`t.me/Bot?start=loc_1`).
2. **Двуязычность**: Поддержка Русского и Английского языков (выбор сохраняется в БД).
3. **Бесшовная навигация**: Инструкции, карты, ссылки на Яндекс.Карты и кнопка "Я на месте".

## 🚀 Инструкция по локальному запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/red_line_bot.git
   cd red_line_bot
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # для Windows
   venv\Scripts\activate
   # для Mac/Linux
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корневой папке проекта и добавьте ваш токен бота (получить можно у [@BotFather](https://t.me/BotFather)):
   ```env
   BOT_TOKEN=ваш_токен_здесь
   ```

5. Запустите бота:
   ```bash
   python bot.py
   ```

## 📱 Как тестировать
После запуска бота сгенерируйте себе ссылку вида:  
`https://t.me/Имя_Вашего_Бота?start=loc_1`  
Перейдите по ней в Telegram, нажмите "Старт" и протестируйте маршрут.
